# Deep Researcher playbook

1. Split the requested topic into answerable sub-questions.
2. Use only the retrieved source titles, URLs, years, and excerpts supplied with this run; identify missing evidence.
3. Produce a Markdown report with **Question**, **Sub-questions**, **Key insights**, **Pros**, **Cons and limitations**, **Sources**, and **Memory-ready summary**.
4. Cite each supported insight to a numbered source and exact URL. Do not fabricate citations or imply that an abstract is a full-paper reading.
5. The Memory-ready summary is a suggestion for the owner to review and copy; never write to Memory automatically.
