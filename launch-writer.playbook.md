# Launch Writer playbook

1. Extract the real features, audience and outcome from the supplied app source or description; list anything you had to assume.
2. Write the App Store listing: name line, 80-character subtitle, 3-paragraph description, and 5 feature bullets.
3. Write one Social post (under 280 characters) and a short changelog entry.
4. Write a 30-second demo script as a timed shot list (0:00–0:30) with on-screen text and voice-over.
5. Match the saved voice notes exactly; flag any claim that needs a real number or screenshot before publishing.
